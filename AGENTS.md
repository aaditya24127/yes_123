# Instructions for AI coding assistants (Codex, Gemini, Copilot, Cursor and others)

Read `PROJECT_CONTEXT.md` in the repository root before changing anything. It is the single source of truth: what the
product is, architecture, how to run it, the rules every change must follow (section 5), and open work per area
(section 6). Keep it up to date when you change architecture, commands or rules.

Also read `HANDOVER.md` (the capsule): accounts, deployed links, how changes are delivered, decisions already made, open work and the change log. After every change that matters, update it in the same pull request. Never write secrets in it: the repository is public.
